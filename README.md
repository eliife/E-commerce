# VELORA | E-Ticaret Web Uygulaması

VELORA, kadın çanta, cüzdan ve deri aksesuar ürünlerini sergilemek amacıyla geliştirilmiş full-stack bir e-ticaret web uygulamasıdır.

Proje; modern, minimalist ve kullanıcı dostu bir alışveriş deneyimi sunmayı hedeflemektedir. Frontend tarafında Next.js ve React, backend tarafında ise Node.js ve Express.js kullanılarak geliştirilmiştir.

## ✨ Özellikler

- **Ürün Kataloğu:** Ürünleri listeleme ve inceleme.
- **Kategori Sayfaları:** Çanta, cüzdan ve yeni gelen ürünleri kategorilerine göre görüntüleme.
- **Ürün Detay Sayfası:** Ürün görsellerini, açıklamalarını ve özelliklerini inceleme.
- **Alışveriş Sepeti:** Ürünleri sepete ekleme ve sepeti yönetme.
- **Favoriler:** Beğenilen ürünleri favori listesine ekleme ve yönetme.
- **Kullanıcı İşlemleri:** Üyelik, giriş ve kullanıcı hesabı işlemleri.
- **İlgili Ürünler:** Benzer ürünleri görüntüleme.
- **Blog:** Marka ve ürünlerle ilgili içerikleri inceleme.
- **Duyarlı Tasarım:** Farklı ekran boyutlarına uyumlu kullanıcı arayüzü.
- **SEO Optimizasyonu:** Sayfa bazlı meta verileri, canonical URL, sitemap, robots.txt ve yapılandırılmış veriler.

## ⚙️ Kurulum

### Gereksinimler

- Node.js
- npm
- MongoDB

### 1. Projeyi Klonlama

```bash
git clone <repository-url>
cd <project-folder>
```

### 2. Backend Kurulumu

Proje ana dizinindeyken backend klasörüne geçin:

```bash
cd backend
npm install
npm run dev
```

Backend API varsayılan olarak aşağıdaki adreste çalışır:

```text
http://localhost:5000
```

### 3. Frontend Kurulumu

Yeni bir terminal açarak proje ana dizinine gidin ve frontend klasörüne geçin:

```bash
cd frontend
npm install
npm run dev
```

Frontend uygulamasına aşağıdaki adres üzerinden erişilebilir:

```text
http://localhost:3000
```

### 4. Ortam Değişkenleri

Projenin çalışması için frontend ve backend taraflarında ortam değişkenlerinin tanımlanması gerekmektedir.

- **Frontend:** `frontend/.env.local`
- **Backend:** `backend/.env`

Ortam değişkenleri dosyaları, proje yapılandırmasına uygun şekilde oluşturulmalı ve gerekli değerlerle doldurulmalıdır.
